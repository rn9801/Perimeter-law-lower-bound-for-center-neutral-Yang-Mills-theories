# Perimeter law lower bound for center-neutral Yang–Mills theories

The paper proves a perimeter-law lower bound for rectangular Wilson loops in
lattice Yang–Mills theory in dimension three and higher, for compact gauge
groups with a faithful unitary action representation and a center-neutral
Wilson representation.
The result holds at every positive coupling for which the stated
translation-invariant infinite-volume limit exists. The Lean formalization
verifies the main theorem and its proof steps.
